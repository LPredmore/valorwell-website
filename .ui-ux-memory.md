# ValorWell UI / UX Memory

**Status:** Durable design memory for the public ValorWell website
**Established:** September 4, 2026 from canonical ClickUp brand sources and the current website implementation

## Brand foundation

- Primary type family: `Trebuchet MS`, with Arial / Helvetica / sans-serif fallbacks.
- Master-brand anchor: ValorWell Evergreen `#3B5147`.
- Primary light surface: Warm Canvas `#F4F1E8`.
- Beyond The Yellow movement accent: Signal Yellow `#D7A92E`, used selectively rather than as the page foundation.
- Ember `#B24A3A` is a controlled tension / warning accent, used sparingly rather than as a default brand accent.
- Utility Ink: `#111814`; White remains a utility neutral.
- The codebase retains legacy semantic aliases such as `--navy` and `--gold-accent`; `--navy` is intentionally retuned to Evergreen in `src/index.css`.

## Visual character

ValorWell should feel mission-led, human, grounded, direct, editorial, action-first, credible, and operational. It should be warm without becoming soft and bold without becoming militarized.

Avoid generic healthcare blue, soft all-sage therapy branding, patriotic red/white/blue systems, military stencil/tactical motifs, flag-heavy visuals, generic nonprofit templates, SaaS gradients, decorative typefaces, or a disconnected yellow BTY sub-brand.

## Maturity and voice standard

- ValorWell should present itself as an operating organization, not argue for permission to be taken seriously.
- Prefer specific facts, operating details, dated metrics, policies, procedures, and direct boundaries over self-certifying adjectives.
- Do not use words such as `ethical`, `legitimate`, `credible`, `transparent`, `responsible`, `real`, or `verified` primarily to validate ValorWell itself when the same point can be demonstrated with evidence.
- Keep necessary clinical, legal, coverage, eligibility, crisis, payment, and operational boundary language even when it is cautionary.
- One major message per page and one dominant idea per section are preferred. Strong brand statements should be selective rather than stacked throughout a page.
- When a claim can be demonstrated, show the evidence rather than adding a slogan that tells the visitor what conclusion to reach.
- About should explain what ValorWell is and how the organization is structured. Mission should explain why it exists. Impact should carry outcome evidence. Conversion pages should lead with decision information and process.

## Layout and hierarchy

- Prefer strong editorial hierarchy, whitespace, and deliberate section pacing over dense card grids.
- Use progressive disclosure for secondary data and specialist detail.
- Above-the-fold content should establish what the page is, who it is for, and the next action quickly.
- One dominant idea per section is preferred.
- Use existing max-width container patterns (`max-w-6xl`, `max-w-7xl`) and established spacing scales unless a page source requires otherwise.
- Large Evergreen sections can create authority and rhythm; Warm Canvas / paper surfaces should remain the majority of most pages.

## Interaction and accessibility

- Target WCAG 2.2 AA.
- Preserve semantic landmarks and heading order.
- All interactive controls need visible keyboard focus.
- External links should clearly indicate destination/action and use safe new-tab attributes when opened externally.
- Touch targets should be approximately 44px minimum where practical.
- Mobile layouts must not horizontally scroll at 320px and should stack CTAs cleanly.
- Respect `prefers-reduced-motion` when adding meaningful motion; avoid motion required for comprehension.

## Beyond The Yellow feature-page pattern

A BTY organization page should spotlight the guest organization rather than make the story primarily about ValorWell. Preferred sequence is concise organization promise + episode, why the work is relevant, evidence/impact, how the work operates, audience-specific paths, deeper details, direct organization-owned CTAs, then a short BTY close.

The main Beyond The Yellow landing page should lead with published conversations and featured organizations. Selection philosophy and movement language are supporting context rather than the primary proof that the series matters.

Do not invent interview quotations or timestamps when transcript evidence is unavailable.

## Implementation discipline

Before adding a materially new page, inspect existing routes, design tokens, shared layout, comparable pages, and the controlling ClickUp page source. Run syntax/type/build/test/lint checks where tooling permits and report unverified areas explicitly rather than treating intended code as verified behavior.
